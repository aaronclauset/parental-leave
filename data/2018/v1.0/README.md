# Version 1.0 (2018)

`parental_leave_policies.tsv` is the original data set of paid parental leave for faculty at U.S. and Canadian universities, published in April 2018 with A. C. Morgan, S. F. Way, M. Galesic, D. B. Larremore and A. Clauset, "Paid parental leave at US and Canadian universities" (2018), and corrected through January 2019. It is unchanged. The same file is also at the repository's root, for existing links.

Version 2.0 (`../v2.0/`) re-collects the same institutions from their governing documents. How the two versions differ is in `../v2.0/v1_v2_differences.csv` and the [release notes](https://aaronclauset.github.io/parental-leave/release-notes/2018-v2.0.html). The 2018 website that presented this data set is archived in `archive/2018-v1.0/` ([view it](https://aaronclauset.github.io/parental-leave/archive/2018-v1.0/)).
